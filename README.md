# Network Port Scanner 🔍

A Python-based network port scanner that scans hosts for open TCP ports, detects basic services, and generates reports.

---

## ⚙️ Features
- TCP port scanning using sockets
- Service detection (banner grabbing basics)
- Multithreaded scanning (faster execution)
- Clean output for analysis

---

## 🛠️ Tech Stack
- Python
- Sockets
- Threading
- (Optional) Nmap integration

---
